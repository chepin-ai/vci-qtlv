## (a) 四范式碰撞图 —— **pass**

同构判定成立，理由分列：

- **P1 区间算术证书 ↔ 联邦级名体系**：区间证书的本质是“对每个数值给出含真值的可机检包络”，与联邦级名体系“对每个对象给出可机检的唯一实名锚点”在结构上同型：都是**全称量化下的可验证包络**。判定准确。
- **P2 SAT 证明证书 ↔ schema 机检**：DRAT/LRAT 类证书把“求解器说 UNSAT”降级为“检查器可独立复核的证明对象”，与 schema 机检把“模式声称合规”降级为“可独立复核的实例”同构。判定准确。
- **P3 形式化证明助手 ↔ fp 互锚**：助手保证“证明项类型检查通过”，fp 互锚保证“多源指纹互相约束”，两者的共性在于**跨独立实现的交叉不变量**。判定准确，但注意二者并非同一强度：助手是单内核全称保证，fp 互锚是概率性结构不变量的多重独立采样。建议在图中标注“同构层级=结构同构，非强度同构”。
- **P4 PINN 失败模式 ↔ 退火路径**：这一项同构度最弱。PINN 失败模式是**症状分类**，退火路径是**过程控制**。同构成立的唯一读法是：两者都在“非凸能量景观上暴露不可达/伪收敛区域”。若碰撞图意在指出“失败模式的拓扑等价于路径上的鞍点/势垒结构”，可成立；若意在断言二者机制同一，则**过强**。建议在 M4 的注释中显式限定为“景观层同构”。

**结论**：四范式碰撞图作为**结构同构层**的判定准确；P4 需加限定语，其余三项直接成立。

## (b) M4 / M5 / M6 入册资格 —— **pass（M5 附域限）**

入册门槛为“洞见级镜像律”，需满足：跨域可迁移、可证伪、可操作化。逐条：

- **M4 延拓律（curriculum ≡ 退火 ≡ 同伦）**：**入册**。三者在“以连续参数族把难问题降为可解问题族”的意义上确实同构；curriculum 是离散同伦参数化，退火是随机同伦，同伦方法是连续同伦。可证伪点：存在 curriculum 有效但不可退火化的反例即可驳。**建议附限制**：同构成立在“参数族单调嵌入”条件下，非单调 curriculum 不纳入。
- **M5 TCB 最小化律（求解器不可信 + 小型检查器 + 检查器须被检查）**：**入册，但降域限**。前两句是 de Bruijn 准则的标准形式，已是工程共识；第三句“检查器须被检查”才是洞见，且它**触发无限回归**。因此 M5 必须以域限形式入册：*在有限预算下，检查器链的递归检查深度由可承受的 TCB 规模决定，回归在“可接受的最小锚点”处截断*。若无此域限，M5 是自我指涉悖论而非律。
- **M6 审计锚律（内容寻址为第三方复核前置）**：**入册**。内容寻址把“复核对象”从“声称的内容”变为“可独立重取的内容”，这是第三方复核的**必要条件**而非充分条件。判定准确，且与 P2 证书化路径一致。可证伪点：存在无需内容寻址即完成第三方复核的机制（例如带外可信信道）——但那实际是把锚点外移，M6 仍成立。

**结论**：M4、M6 直接入册；M5 以“有限回归截断”域限形式入册。

## (c) FM-015 入 FM-LIB —— **pass（建议降格标注）**

drat-trim 案（检查器接受恶意假证书）是**真实且可复现**的实例，满足 FM-LIB 的“有实证锚”要求。但需注意：

- 该 failure mode 的本质不是“检查器算法错误”，而是**检查器规格与被检查对象规格之间的空隙**（检查器只验证“证书格式合法”，未验证“证书语义强制”）——即**规格-实现缝隙型失败**。
- 因此 FM-015 应以 **“检查器缺检模式（checker under-specification）”** 入册，并**显式引用 M5 域限**作为其缓解路径（检查器须被检查，但须在可截断深度内）。
- **不建议**把它归为“检查器 bug”类，那会误导向“打补丁”而非“补规格”。

**结论**：入 FM-LIB，标注为“规格缝隙型 / 与 M5 域限互指”。

## (e) F-X1 区间证书实验效力 —— **pass（限求值层）**

6/6 PASS、外向舍入包络 |marg| ≤ 1.55e-11、cost 宽 1.32e-13、f64/f80 双包含齐备，作为**求值层**（即“给定表达式，证书包络可机检”）的效力成立。亚 LP 松弛由认证不可行性解释，逻辑自洽。

**必须写明的不外推边界**：
- 该实验验证的是**包络的机检可行性**，不是**原问题解的存在性**。
- 1.55e-11 的 margin 是**外向舍入后**的包络宽度，不可回读为“真值距边界 1.55e-11”。

**结论**：求值层效力认可；存在性层、精度回读、真值夹逼三项明确**不外推**。
