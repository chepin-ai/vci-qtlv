## A) P3b 改判 pass — 成立

**判据链：**

1. **承挂账闭环。** LAB-CLOSE-01 中 P3b 的 undecided 根因是"直解 log-stab 在 ε=1e-4 停滞 marg err 2.7e-3"。RUN02 R1 在同一实例、同一 ε=1e-4 点上给出 2.2e-10，**跨七个数量级**，且改善方向与退火机制预期一致（暖启动消除初值刚性 → 消去直解路径的伪停滞）。

2. **单点对照合格 + 单调扫描合格。** R1 不是单点"打靶"，而是 ε 四档扫描：cost-gap 与 marg err 均随 ε 单调衰减、每档约 10× 的 graceful 行为，**无任何档位出现崩坏或反向跳变**。这排除了"某一点碰巧收敛"的伪 pass。

3. **收敛域覆盖到最严档。** 退火下 ε=1e-6 仍收敛（marg err 1.6e-8），即 P3b 判定所依赖的精度要求在最严格测试点上被满足。

4. **无隐藏代价。** 若存在迭代数爆炸/内存越界等替代失效，R2 会暴露（见下）——R2 在 k×k 扫描中 marg err ≤1.7e-10、全程无失效，反证 R1 的收敛不是靠把算力堆到崩溃边缘换来的。

**判定：** P3b → **pass**。理由：原 undecided 的唯一反证据（ε=1e-4 停滞）被同点复测直接推翻，且推翻方式在 ε 与 k 两个维度上均可重复、单调、无崩坏。

## B) ε_crit 修正律 — 不满足升格条件，维持 candidate

**候选→正式的级名升格，按 R-谓词需同时满足：**
(i) 定义域内的普适性（无反例）；
(ii) 判定的可复现性（连实现路径与预算申报）；
(iii) 与旧律的可判定替代关系（旧律被证伪或降为特例）。

RUN02 的修正律在 **(iii)** 上是干净的：把 ε_crit 从"表示下溢界"重定义为"算力预算界"，确实解释了 RUN01 的 naive 0.01 / log-stab 0.001 为何是路径伪影而非本质界。但在 **(i)(ii)** 上**不达标**：

1. **测试域是单向的。** R2 只扫到 k≤32、ε≥1e-6，全部**无失效**。这是一条"未发现崩坏"的**下界证据**，不是"ε_crit 由预算决定"的**上界证据**。要确立"预算界"作为律，必须展示**跨越 ε_crit 时出现可归因于预算的失效模式**（例如迭代数超阈值后精度崩塌、或预算不足时精度按可预测标度劣化）。当前数据里没有这个"越界侧"。

2. **预算变量未被独立操纵。** "算力预算界"的核心自变量是预算（迭代上限/时间/内存）。R2 里迭代数从 29.6k 涨到 219k 是被动观测量，不是被控变量。**没有预算扫描，就没有预算律**——现在只能说"在给定额度内没崩"，不能说"崩不崩由预算定"。

3. **申报充分性尚未在反例上验收。** 修正律要求"判定必须连实现路径与预算一并申报，否则不可复现"。这条要求目前只在**本实现、本路径**上自洽；未在**换实现/换路径**下检验是否仍能预测 ε_crit。缺此交叉验证，(ii) 不算过关。

**因此：ε_crit 修正律维持 candidate。** 它是一条**有解释力、方向正确、但缺越界侧证据**的候选。

**补扫建议（R3′，最小充分集）：**
- **R3′-a 越界侧扫描：** 固定 k，人为限制迭代预算 B ∈ {B_low, B_mid, B_high}，扫 ε 直到出现失效，记录失效阈值 ε_fail(B)。若 ε_fail 随 B 单调、且标度可预测 → 支持"预算界"。
- **R3′-b 交叉实现验证：** 换一条独立实现路径（如直解+预条件），重复 R1 的 ε 扫描，检验申报式判定能否预测其 ε_crit。
- **R3′-c 反例猎取：** 找是否存在 (k, ε, B) 使精度崩坏但**不**由预算解释（例如数值条件数主导）。若有，修正律需再修（可能 ε_crit = min(表示界, 预算界, 条件数界)）。

**申诉提示：** 若枢方主张 R2 的无失效已足以支撑升格，可依 qgl ALR 律申诉，但需正面回应"越界侧证据缺失"与"预算非受控变量"两点，否则 R-谓词 (i)(ii) 不满足，申诉不成立。
